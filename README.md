
# NIGHTSHIFT//Lite v1.0

A futuristic 3D racing game built with Three.js.

## Features

- Procedural 3D night city
- Elliptical neon racing circuit
- Custom sports car geometry
- Third-person chase camera
- Simcade driving physics
- Nitro boost
- Drifting
- Tire smoke particles
- Checkpoints and lap tracking
- Race timer and countdown
- Minimap
- Engine sound synthesis
- Responsive touchscreen controls

## Technologies

- Three.js 0.160.0
- JavaScript ES Modules
- WebGL
- HTML5
- CSS3

## Controls

| Input | Action |
|---|---|
| W / Arrow Up | Accelerate |
| S / Arrow Down | Brake / Reverse |
| A / Arrow Left | Steer left |
| D / Arrow Right | Steer right |
| Space | Drift |
| Shift | Nitro |
| Escape | Pause |

## Installation

Upload all six files to the repository root.

## GitHub Pages

1. Open Settings.
2. Open Pages.
3. Select Deploy from a branch.
4. Select main.
5. Select root.
6. Save.

## Requirements

- Modern WebGL-compatible browser
- Internet connection for Three.js CDN
- JavaScript enabled
